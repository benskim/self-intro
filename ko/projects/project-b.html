Video Data Curation & MLOps

데이터 품질 개선을 모델 학습과 운영 파이프라인에 연결하다

영상·음성 데이터의 품질 기준과 자동 정제 파이프라인을 만들고, 학습 샘플과 GPU 학습 시간을 줄인 데이터 큐레이션·MLOps 프로젝트입니다.

학습에 쓰는 샘플 수 약 20 ~ 30% 감소 정제 기준으로 노이즈 데이터를 걸러 냄

GPU 학습 시간 최대 40% 감소 같은 원천 데이터·모델·하드웨어에서 정제 전후 비교

My Role & Contribution 역할과 기여

영상 데이터의 품질 문제를 정량적으로 분석하고, 데이터 정제 기준부터 딥러닝 기반 품질 평가, MLOps 환경 구축까지 수행했다.

  • SQL, Python, Librosa, OpenCV로 메타데이터 추출과 품질 분석
  • 데이터 품질 기준과 정제 규칙 설계
  • CNN·Vision Encoder 기반 데이터 품질 평가 모델 학습과 적용
  • 데이터 수집·전처리·품질 필터링 파이프라인 구현
  • MLflow 기반 실험 추적과 모델 관리 환경 구축
  • 데이터셋 버전 관리와 학습 설정 재현 환경 구성

Data Quality Analysis 데이터 품질 분석

영상·음성 데이터의 품질 편차가 학습 효율과 모델 성능에 주는 문제를 분석했다.

주요 발견

  • 접근·수집 품질: 확보한 영상의 20%가 access denied 상태로, 공개 메타데이터와 맞지 않았다.
  • 대표성: 아시아인 비중이 5% 미만으로 서구권에 치우쳐 있었다.
  • 음성 품질: 음성 파일의 4%가 노이즈 허용 한계(SNR)를 넘었다.
  • 영상 품질: 이미지의 15%에서 얼굴 검출에 실패했고, 특정 밝기 영역에 치우쳐 있었다.

분석 결과로 얼굴 인식에 영향을 주는 crop 크기·유사도 기준과 최소 SNR, 최소 해상도 같은 정제 임계값을 정했다.

Data Curation & Model Implementation 데이터 정제와 모델 구현

규칙 기반 검증과 딥러닝 기반 품질 평가를 결합한 정제 구조를 구현했다.

  • 영상·음성 메타데이터 자동 추출
  • 규칙 기반 품질 검증과 필터링
  • CNN·Vision Encoder 기반 품질 평가 모델 학습과 적용
  • 품질 기준에 따른 학습 데이터 선별(Accept / Review / Reject)
  • 정제 데이터와 모델 학습 결과 연결

Accept Review Reject

Experimental Environment 실험 환경

같은 원천 데이터·모델·하드웨어에서 정제 적용 여부만 바꿔 성능과 학습 자원 소모를 비교했다.

항목 구성
데이터셋 VoxCeleb1, VoxCeleb2
데이터 처리·얼굴 분석 FFmpeg, RetinaFace
얼굴 표현 ArcFace
하드웨어 NVIDIA RTX 3090

MLOps Implementation MLOps 구현

MLflow 기반 실험 추적, 모델 관리, 데이터셋 버전 관리가 되는 MLOps PoC를 만들었다.

  • 실험 설정과 학습 결과 추적
  • 모델 버전 관리
  • 데이터셋 버전 관리
  • 학습 환경과 설정 재현(seed, 하이퍼파라미터, 데이터셋 버전 고정)
  • 데이터 처리와 모델 학습 단계 연결

Measured Results 측정 결과

같은 원천 데이터·모델·하드웨어에서 정제 적용 전후를 비교했다.

  • 학습에 쓰는 샘플 수: 약 20 ~ 30% 감소
  • GPU 학습 시간: 최대 40% 감소

함께 비교한 항목: 정제 전후의 모델 성능, 학습 안정성과 과적합 지표.

Limitations & Expected Impact 한계와 기대 효과

정제 적용 전후 비교는 한 가지 설정(위 데이터셋·모델·하드웨어)에서 한 것이다. 반복 실험이나 다른 모델·데이터에서도 같은 효과가 나는지는 확인하지 않았고, 데이터 품질 지표와 모델 성능의 인과관계를 주장하지 않는다.

데이터 품질 관리와 실험 추적을 모델 개발 과정에 넣어, 앞으로 데이터 관리 효율과 모델 개발 생산성을 높일 기반을 만들었다.
