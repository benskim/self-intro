도출된 가설 분석

가설 1 — AI 결과물이 생성되기까지의 대기 시간(Latency)이 8초를 초과할 경우 유저의 즉각적인 이탈(Drop-out)률이 지수 함수적으로 상승함.

가설 2 — 이미지 생성 실패율(얼굴깨짐현상)이 높을수록 고객 이탈 속도가 비례하여 상승함.

💡 SQL 분석결과: SQL 윈도우 함수를 활용한 사용자 세그먼트 분석 결과, AI 결과물을 2회 성공적으로 수신한 유저의 7day 잔존율이 미경험 유저 대비 3.5배 높음 확인.

지표 정의 및 LTV 모델 Business Metric Optimization

유저 평생 가치(LTV) 및 북극성 지표(North Star Metric) 수식 정립

Metric Formulation

  • Proxy LTV: \(\text{proxy LTV} = 1 / \text{GPU cost}\)
  • North Star Metric: ‘가입 후 24시간 이내에 생성형 AI 결과물 다운로드(또는 공유) 1회 이상 달성 수치’

Unit Economics 그로스 전략 — proxy LTV/CAC 비율을 3.0 이상으로 유지하여 유닛 이코노믹스(Unit Economics) 안정화를 달성하는 그로스 전략 수립.

Hypothesis Testing A/B 테스팅 시나리오 설계

가설 검정을 위한 실무형 A/B 테스트 시나리오 및 통계적 설계

실험 세그먼트 콘텐츠 기획 가설
대조군 (Group A) 기존 랜덤 콘텐츠 (80% 개인 업로드 콘텐츠, 20% 내부)
실험군 (Group B) 장르 기획 콘텐츠 (시네마틱, Y2K, 만화, 병맛 등)
  • 주지표: 영상 변환율 = 콘텐츠 노출 유저 중 AI 영상 생성에 성공한 유저 비율 (기준 14.2%)
  • 배정 방식 / 기간: Firebase Remote Config(A/B Testing)로 신규 유저를 무작위 50:50 배정(콘텐츠 노출 정책 값 분기), 14일 (요일 효과 2주기). 군 정보는 user property와 액션 로그에 함께 기록해 BigQuery·Amplitude에서 군별 분석.
  • 샘플 사이즈 산정: 유의수준 \(\alpha = 0.05\), 검정력 \(1-\beta = 0.80\), 최소 검출 효과(MDE) +6.5%p(14.2% → 20.7%) 기준 군당 최소 532명, 14일 기준 일일 세그먼트당 최소 38명.

실전 A/B Test 수행 통계적 유의성 검정

A/B 테스트 수행 결과 분석 및 신뢰도 95% 수준에서의 유의성 검증

독립표본 T-검정 및 카이제곱 검정을 통한 전환 비율 검정 수행 (군당 576명, 일일 약 41명).

실험군(B) 영상 변환율 향상 +5.6%p (약 +39%) A 14.2% → B 19.8% (82명 → 114명 / 군당 576명)

통계 검정 수치 p = 0.012 < 0.05 차이의 95% 신뢰구간 +1.2 ~ +9.9%p

결론: 우연에 의한 차이가 아님을 통계적 유의도 수준에서 검증하여 새로운 서비스 시나리오로 정식 롤아웃 의사결정. 관측 차이(+5.6%p)는 설계 MDE(+6.5%p)보다 작아 검정력은 약 71%이므로, 롤아웃 후 모니터링으로 효과 크기를 재확인.

상세 재현 분석은 Report: A/B 테스트 분석 노트에서 확인할 수 있습니다.

::: {.lead-line}

| 실험 세그먼트 | 콘텐츠 기획 가설 |

## [실전 A/B Test 수행]{.tag} 통계적 유의성 검정

::: {.lead-line}
A/B 테스트 수행 결과 분석 및 신뢰도 95% 수준에서의 유의성 검증
