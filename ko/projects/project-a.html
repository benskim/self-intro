Gen-AI B2C Growth Analytics

사용자 행동 분석과 실험으로 생성형 AI 앱의 콘텐츠 생성 전환을 개선하다

My Role & Contribution 역할과 기여

B2C 생성형 AI 서비스의 사용자 획득부터 콘텐츠 생성, 재방문까지 전체 퍼널을 분석하고, 데이터 기반 성장 전략과 실험을 주도했다.

  • Firebase 이벤트 로깅과 사용자 ID 매핑 구현
  • AppsFlyer 등 유입 데이터와 사용자 행동 데이터 연동
  • BigQuery 기반 데이터 통합과 분석 환경 구축
  • Tableau 성장 지표 대시보드 구축
  • A/B 테스트 설계, 사용자 그룹 배정, 결과 분석과 후속 실행 주도
  • 정기 지표 리뷰로 유관 부서와 개선 과제 공유

Problem & Analysis 문제와 분석

사용자 행동 데이터를 분석해 설치 뒤 콘텐츠 생성으로 이어지는 단계에서 이탈이 몰리는 구간을 찾았다. 콘텐츠 생성 대기 시간과 생성 실패율을 주요 개선 가설로 세우고, 첫 생성 뒤의 반복 생성 행동과 잔존율의 관계도 분석했다.

2회 이상 생성을 경험한 코호트의 7일 잔존율이 비교군보다 약 3.5배 높게 관측됐다. 사용자 행동 패턴의 차이를 보여 주는 관찰 결과이며, 반복 생성 경험이 잔존율을 높였다는 인과관계를 뜻하지는 않는다.

Experiment Design & Execution 실험 설계와 수행

분석 결과를 바탕으로 콘텐츠 생성 경험 개선 가설을 세우고 A/B 테스트를 직접 설계·주도했다.

  • 실험 가설과 핵심 성과 지표 정의
  • 실험군·대조군 배정과 데이터 수집
  • 전환율 기반 실험 결과 분석
  • 결과를 바탕으로 서비스 개선과 롤아웃 의사결정 지원
항목 내용
핵심 지표 콘텐츠 생성 전환율: 콘텐츠에 노출된 사용자 중 AI 콘텐츠 생성에 성공한 사용자 비율
배정 Firebase Remote Config로 신규 사용자를 50:50 무작위 배정
기간 14일(요일 효과 2주기)
설계 기준 유의수준 0.05, 검정력 0.80, 최소 검출 효과 +6.5%p(14.2% → 20.7%)

Measured Results 측정 결과

A/B 테스트에서 콘텐츠 생성 전환율 개선을 확인했다.

  • 콘텐츠 생성 전환율: 14.2% → 19.8% (+5.6%p)
  • 통계 검정: p = 0.012
  • 콘텐츠 재생성 성공률: 18% → 33%
  • CAC: 12% 감소

관측된 차이(+5.6%p)는 설계 때 잡은 최소 검출 효과(+6.5%p)보다 작아, 효과 크기는 롤아웃 뒤 모니터링으로 다시 확인하기로 했다. 실험 결과를 바탕으로 개선안을 실제 서비스에 롤아웃했다.

Business Execution 실행

분석 결과가 실제 서비스 개선으로 이어지도록 데이터 기반 의사결정 체계를 만들었다. Tableau 대시보드로 핵심 성장 지표를 모니터링하고, 정기 지표 리뷰에서 유관 부서와 개선 방향과 실행 과제를 공유했다.
