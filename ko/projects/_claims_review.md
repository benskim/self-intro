# 프로젝트 A·B·C 성과 문장 구분 초안 (검토용, 사이트에 공개되지 않음)

> **2026-11-28 갱신:** 이 초안을 바탕으로 작성자가 정한 가이드라인에 따라 `project-a/b/c.qmd`를 새로 썼다. 아래 표는 고치기 전 문장 기준이다.
파일 이름이 밑줄(`_`)로 시작해 Quarto가 렌더링하지 않는다. 작성 2026-11-28. **구분은 문장만 보고 붙인 제안이다. 사실 여부와 본인 기여 범위는 작성자만 확인할 수 있다.**

## 구분 기호

| 기호 | 뜻 | 페이지에 쓸 때 |
|---|---|---|
| **직접** | 본인이 직접 수행 | "~했습니다" |
| **주도** | 본인이 설계·주도하고 팀이 함께 수행 | "~을 설계·주도했습니다(팀 n명)" |
| **팀** | 팀이 수행, 본인은 일부 참여 | "팀에서 ~했고, 저는 ~을 맡았습니다" |
| **측정** | 실제로 측정한 성과(기간·기준·방법이 있음) | 숫자 + 측정 기준 + 기간 |
| **기대** | 목표·기대 효과·정성 평가(측정 안 함) | "기대 효과", "목표"로 표시하고 KPI 카드에서 뺌 |
| **확인 필요** | 문장만으로는 판단할 수 없음 | 작성자 확인 뒤 위 중 하나로 |

## 가장 먼저 볼 것

**A/B 테스트 수치(프로젝트 A).** 사이트에서 내린 A/B 노트에는 "군별 전환 수(A 82명, B 114명 / 군당 576명)는 보고된 전환율과 p값에 맞춰 정리한 값"이라는 안내가 있었다. **같은 숫자가 프로젝트 A 페이지에는 안내 없이 실제 결과처럼 나온다**(`project-a.qmd` 160·163·189행). 실제 로그에서 센 값이 아니라면, 노트를 내린 이유가 이 페이지에도 그대로 해당한다.
